# Theme art

Background images for themes go here. A theme uses one with `art: { image: 'art/themes/your-file.webp' }` in
`js/themes.js` (see DEVELOPER.md, "Adding a theme").

- WebP or JPEG, about 1200 px wide and under 300 KB, so it loads fast on a phone.
- Keep it quiet and dark (or light, for a light theme): text and cards sit on top of it.
- Only art you made or have the rights to use.
