# Security

Roll Credits is being tested by real people, so if you find a security problem, please tell us instead of
testing how far it goes.

## How to report

Use **Settings → Send Feedback** in the app (you'll need to be signed in). Start the message with
"Security" and include what you found and how to see it again. Please don't open a public GitHub issue for it.

## What counts

- Reading, changing, or deleting another person's data
- Getting admin access or using admin tools without being an admin
- Getting at keys or secrets
- Anything that could break the app for everyone

## Ground rules

- Only test with your own account and your own data.
- Don't try to access or change anyone else's account or data.
- Don't run scripts that flood the app or its services with requests.
- Don't post details publicly until the problem is fixed.

Thanks for helping keep Roll Credits safe.
